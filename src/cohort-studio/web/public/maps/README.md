World boundaries are derived from Natural Earth 1:110m Admin 0 Countries
(https://github.com/nvkelso/natural-earth-vector/tree/master/geojson), a
public-domain dataset (https://www.naturalearthdata.com/about/terms-of-use/).
Country names and geometry are retained; other properties are omitted.
Natural Earth boundaries represent de facto control and are not a geocoder.
