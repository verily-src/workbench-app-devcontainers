# custom-jupyter-ml

Custom Workbench JupyterLab app with pre-installed packages, generated by the
`CREATE_CUSTOM_APP_WITH_PACKAGES` skill.

- **Python packages:** pandas, numpy, scikit-learn
- **R packages:** tidyverse, ggplot2
- **Port:** 8888

Packages are installed at build time via the `common-packages` feature, so the app launches with
them ready — no `pip install` / `install.packages()` needed.

## Usage

1. Commit this folder under `src/custom-jupyter-ml/` and push.
2. In the Workbench UI (Container setup), point a custom app at:
   - **Repository URL:** `https://github.com/verily-src/workbench-app-devcontainers.git`
   - **Repository branch:** `package-installation`
   - **Repository folder path:** `src/custom-jupyter-ml`

## Note on the feature path

This test folder references the feature by **local path**
(`./.devcontainer/features/common-packages`) because the feature is not yet published to ghcr.
Once released, switch to the ghcr path:
`ghcr.io/verily-src/workbench-app-devcontainers/common-packages`.
