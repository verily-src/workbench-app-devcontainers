# Harmony Data Harmonization Dashboard

Verily Workbench Custom App definition for the Harmony Streamlit dashboard.

## Launching in Verily Workbench
1. Open **Apps → New App -> Custom App**.
2. Set **Repository URL** to `https://github.com/verily-src/workbench-app-devcontainers` and **Folder path** to `src/harmony-dashboard`.
3. Set **Application port** to `8502`.
4. *(Optional)* Override `GCS_BUCKET`, `GCS_ROOT_PREFIX`, `HARMONY_DATASET_NAME`, `HARMONY_DATASET_SUBTITLE`, or `HARMONY_LOCAL_PATH` under **Environment variables**.
