# Workbench tools in OpenCode

The generated Workbench context and its guides are shared with several agents.
In OpenCode, tools from the `wb` MCP server use the `wb_` prefix. References such
as `mcp__wb__workspace_list_resources` in a guide refer to the corresponding
`wb_workspace_list_resources` tool exposed in this session. Use the actual tool
names and schemas available to you.

Read the detailed guides in `~/.claude/skills/` when they are relevant to the
task. They are available as files; do not assume they are native OpenCode skills.
